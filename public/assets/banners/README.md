# Banner assets

- `candidates/` contains the original AI-generated PNG candidates for manual review.
- `optimized/` contains the compressed WebP files used by the website.
- Images were generated on 2026-10-31 with `gpt-image-2` through a user-provided OpenAI-compatible endpoint.
- Prompts are stored in `tmp/imagegen/` locally and are intentionally ignored by Git.
- The assets are original generations and intentionally avoid existing franchises, characters, logos, text, and watermarks.
